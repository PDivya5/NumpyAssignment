# NumPy Assignment

This repository contains my NumPy assignment programs and practical exercises focused on numerical computing and data processing.

## Concepts Covered

* NumPy Arrays
* Array Creation and Operations
* Dimensions, Shape and Size
* Reshaping and Transpose
* Feature Matrices
* Axis Operations
* Broadcasting
* Matrix Multiplication
* Data Standardization
* Random Number Generation
* Missing Value Handling
* Mean Squared Error (MSE)
* Vectorized Operations
* Image and Batch Data Processing

## Tools and Technologies

* Python
* NumPy
* Jupyter Notebook

## Project File

* `divya_numpy.ipynb` – Contains the NumPy programs, outputs, and practical implementations.

## Objective

The objective of this assignment is to develop practical knowledge of NumPy and understand its use in numerical computation, data preprocessing, and AI/ML applications.

## Learning Outcomes

Through this assignment, I practiced working with arrays, indexing, reshaping, broadcasting, aggregation, standardization, matrix operations, random data, and vectorized computations.
